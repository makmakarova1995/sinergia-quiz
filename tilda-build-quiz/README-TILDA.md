# Квиз C-level для Tilda

## Что вставлять

Вставьте в Tilda весь файл `quiz-cases-t123.html`. Это готовый код блока T123: стили, iframe и автоподстройка высоты уже внутри.

## Как загрузить

1. Снача опубликуйте актуальный `quiz-cases.html` в GitHub Pages.
2. Создайте в Tilda пустую страницу.
3. Добавьте «Библиотека блоков» → «Другое» → **T123 «HTML-код»**.
4. Откройте «Контент» и вставьте весь код из `quiz-cases-t123.html`.
5. Сохраните и опубликуйте страницу. Проверяйте именно опубликованную страницу: в редакторе Tilda JavaScript может не запуститься.
